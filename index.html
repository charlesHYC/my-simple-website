Main Project

An HBM-Based 100 Gbps Traffic Replay Engine

Recorded traffic is loaded into High Bandwidth Memory over PCIe, then read back out by eight parallel read masters and rebuilt into Ethernet frames one per clock cycle. It can either honour the original capture timing or push everything back to back at the line rate.
